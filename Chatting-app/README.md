💬 Chatting Application

A modern real-time Chatting Application built with React Native, Expo, and TypeScript.
This app provides a smooth and responsive messaging experience across Android, iOS, and Web platforms.

🚀 Features
💬 Real-time messaging
🔐 User authentication
📱 Cross-platform support (Android, iOS, Web)
⚡ Fast and responsive UI
🧠 Form validation with Yup & React Hook Form
🔄 Persistent login using AsyncStorage
🌐 API integration with Axios
🔌 Real-time communication using Socket.IO
🎨 Clean and modern UI
