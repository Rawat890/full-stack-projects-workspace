📝 Notes App

A modern and minimal Notes Application built with React Native, Expo, and TypeScript.
This app allows users to create, manage, and organize notes with a smooth and responsive experience across Android, iOS, and Web platforms.

🚀 Features
📝 Create, edit, and delete notes
☁️ Cloud database integration with Supabase
⚡ Fast data fetching using React Query
📱 Cross-platform support (Android, iOS, Web)
🎨 Clean and modern UI
🔄 Real-time and efficient state management
🚀 Smooth navigation with Expo Router
